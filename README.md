# Kaset Connect Demo — Project Initiation → Farm Operations

ต้นแบบแบบ interactive (ไฟล์ HTML เดียว) สำหรับ **ทดสอบความเข้าใจ workflow** ของโครงการเกษตรเชิงพาณิชย์ ร่วมกับผู้ประกอบการเกษตร
ไม่ใช่ระบบจริง และ workflow นี้ยังไม่ได้รับการยืนยัน

**เปิดดู:** GitHub Pages ของ repo นี้ หรือดาวน์โหลดแล้วดับเบิลคลิก `index.html` (หน้า index รวมลิงก์ไปทุกเอกสาร) — ตัวเดโมอยู่ที่ `kaset-connect-demo.html`
ไม่ต้องใช้ internet, backend, login หรือ build

## เดโมนี้แสดงอะไร

`ข้อมูลตลาด → แนวทางการผลิต → ยังไม่รู้ / ต้องตัดสินใจ → สรุปเพื่อตัดสินใจ → เริ่มโครงการ → การดำเนินงาน`

- ข้อมูลทุกช่องมีสถานะหลักฐาน: **ยังไม่ทราบ · มีผู้ให้ข้อมูล · สมมติฐาน · ยืนยันแล้ว**
- อะไรที่ยังไม่ "ยืนยันแล้ว" จะแสดงเป็นเรื่องที่ยังเปิดอยู่ และการเริ่มโครงการไม่ได้ทำให้ข้อมูลกลายเป็น "ยืนยันแล้ว"
- ตัวอย่าง: โครงการแคนตาลูป สุราษฎร์ธานี มีเฉพาะข้อมูลที่มีคนพูดถึงในการสนทนา ข้อมูลที่ไม่มีหลักฐานแสดงว่า "ยังไม่ทราบ"
- ปุ่ม **รีเซ็ตตัวอย่าง** มุมขวาบนใช้เริ่มนำเสนอใหม่ สถานะเก็บเฉพาะในแท็บนั้น

## Document Center (`index.html`)

`index.html` เป็นหน้ารวมลิงก์ไปทุกไฟล์ `.html` / `.md` / `.pdf` ในโฟลเดอร์ เรียงแก้ไขล่าสุดก่อน และแสดงวันที่อัปเดตของแต่ละไฟล์
สร้างจากสคริปต์ `build-index.mjs` — **อย่าแก้ `index.html` ด้วยมือ**

เมื่อเพิ่มหรือแก้เอกสาร ให้อัปเดต index ด้วยวิธีใดวิธีหนึ่ง:

| วิธี | คำอธิบาย |
|---|---|
| `node build-index.mjs` | รันสคริปต์ตรงๆ |
| `/update-index` | slash command ของ Claude Code (`.claude/commands/update-index.md`) |
| `git commit` | pre-commit hook (`.git/hooks/pre-commit`) รันสคริปต์และ stage `index.html` ให้อัตโนมัติ — hook อยู่เฉพาะในเครื่องที่ตั้งไว้ ไม่ถูก clone ตาม repo |

ชื่อและคำอธิบายของการ์ดดึงจาก `<title>` + `<meta name="description">` (HTML) หรือหัวข้อ `#` + ย่อหน้าแรก (Markdown) ควรใส่ meta description ให้เอกสาร HTML ใหม่ ส่วน PDF ใช้ชื่อไฟล์เป็นชื่อการ์ดและแสดงขนาดไฟล์ จึงควรตั้งชื่อไฟล์ให้สื่อความหมาย

## ขอบเขต

- ต้นแบบของสมมติฐานเรื่อง workflow ไม่ได้กำหนด domain model, schema หรือ architecture ของระบบจริง
- ไม่มี AI, marketplace, การเงินจริง หรือผลผลิตจริง ความคืบหน้าหมายถึงขั้นตอนที่เช็คผ่านเท่านั้น
- UI ใช้ design system TUI (CSS variables `--tui-*`) รวมอยู่ในไฟล์เดียว ไม่มี dependency ภายนอก
